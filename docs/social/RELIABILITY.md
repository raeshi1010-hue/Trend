# 公开论坛稳定性

本模块仅作用于ContractorTalk和SkyscraperCity公开路径，不改变YouTube、Reddit或X授权策略。

- 每条公开路径最多2次请求；只有超时、指定临时网络错误和HTTP408/500/502/503/504可重试1次，间隔1秒。
- HTTP401/403/451、429及TLS/证书链错误立即停止该来源，不通过备用页面绕过限制；不关闭证书验证，不自动解验证码。
- 主路径为已有/forums/，备用为同站根目录。仅在普通请求失败、404或没有近期候选时尝试备用，不把备用路径当作独立数据来源。
- 每次保存路径、观察时间、HTTP状态或错误类型、耗时与尝试序号；详情页也记录独立尝试。不给原帖访问失败补写作者/日期。
- 重定向不自动跟随。每来源最多4条论坛候选，每条详情同样有限重试。来源页时限15秒、详情12秒；工作流总时限10分钟。
- 看板可以展开来源请求轨迹，JSON保存完整尝试元数据。测试通过不代表公网来源稳定；长期成功率需连续运行后统计，不在首次运行虚构。

21项测试覆盖原有适配器、配置及新增重试、限流、权限停止、证书错误、同站备用等行为。最终GitHub实测以本期pilot.json和Actions记录为准。
