# 社媒与行业论坛：首轮试采

本模块只在 raeshi1010-hue/Trend 仓库内维护，不依赖其他聊天或本机定时任务。运行 `node scripts/social-pilot.mjs` 可重新生成本目录的 `pilot.json` 和 `index.html`。需要 Node.js 22+，不需要 npm 依赖。不默认启用定时或发布公网。

## 本次观察与限制

精确时间、HTTP状态、网络错误类型和提取条数见pilot.json。本轮12条匿名路径均未提取有效原帖。网络失败不能推断平台要求登录或付费；403/451也仅代表该路径在当前执行环境的结果。未自动绕过挑战、验证码或权限。

当前脚本是可重复的公开路径试采器，不是全平台采集器；HTML成功响应不能证明内容可用。Reddit和RSS有结构化候选解析，其余路径只检测可达性，后续需要专用适配器。试采生成时显示零候选及缺口，不放模拟帖子。

原帖字段验收：原文标题、直链、作者、首发时间、观察时间、国家依据、行业角色、原始互动指标及观测时间、标签、音频来源、证据和核验状态。没有市场证据不依据语言推断地区；未核验内容不判热门。创作建议需要原帖支撑，不能先填固定建议充当分析。

## 接入顺序

1. 先在GitHub Actions或部署主机复测网络，确认环境问题与平台访问限制。
2. 优先YouTube Data API密钥，随后确认Reddit OAuth资格；不将密钥写入仓库。
3. Instagram/Facebook需先明确监测公共主页、指定账号还是全网关键词，再判断授权接口能否覆盖。X需确认开发者权限和额度。TikTok研究接口先确认资格，不能用普通账号授权替代。
4. 若需要付费社媒监听，先做覆盖国家、历史范围、原帖指标及音频字段的试采，另行批准采购。
5. 原帖日期、市场、指标和音频覆盖通过后，再实现日报/周报快照和GitHub部署；目标09:00与周五16:00（北京时间）。GitHub定时运行可能延迟，不能承诺精确到点。

## 官方文档核对

- [YouTube videos.list](https://developers.google.com/youtube/data/reference/rest/v3/videos/list)：snippet/statistics、mostPopular、regionCode。地区榜不代表行业关键词匹配结果。
- [TikTok Research Query Videos](https://developers.tiktok.com/docs/en/research-api-specs-query-videos)：需research.data.basic及访问令牌，可请求music_id及互动字段；region_code是创作者注册国家，不能冒充受众所在地。

其他平台接口范围仍待官方文档及授权实测，不作已支持承诺。
